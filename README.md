# Day 037｜言い過ぎ見直しメモ

> 100日100プロダクトチャレンジ Day 037（2026-09-13）／カテゴリ: 文章チェックツール

## これは何か

書いた販促文を貼り付けると、内蔵した「一度立ち止まって見直したい言葉」のリストと機械的に照らし合わせて、
該当した箇所にマーカーを付け、その言葉がどう受け取られることがあるかを並べる道具です。

**このツールは、法令に違反しているかどうかを判定するものではありません。**
気づきのきっかけを出すだけで、掲載してよいかどうかの判断はしません。

## 解決する困りごと

- 想定利用者: 自分で広告文・チラシ文・LP文・SNS販促文を書く事業者
- 困りごと: 勢いで書いた販促文に「必ず効く」「日本一」「副作用は一切ありません」のような言い切り表現がうっかり混ざり、公開してから「これ大丈夫だったのか」と冷や汗をかく
- 解決方法: 文章を貼るだけで、内蔵の24語に該当する箇所をハイライトし、「なぜ気に留めたほうがよいか」を並べる

## 使い方

`index.html` をブラウザで開き、上部の入力欄に販促文を貼り付けるだけです。
入力するたびに自動で照合されます。ビルド・インストール・ネット接続はいりません。

## 主な機能

- 機能1: 内蔵の要注意ワードリスト（4カテゴリ24語）で検出
- 機能2: 該当箇所のハイライト（背景色＋下線）と、その言葉についての注意文の表示
- 機能3: 「専門家の確認を推奨」の注記を、入力前と結果の直後の2か所に常時表示

## 既知の問題・未完成部分

- `No.1` は半角大文字表記のみを検出します。`no.1`・`Ｎｏ．１` は拾いません
- 同じ趣旨でも語形が違うと拾いません（例:「完全に無料」「必ず効きます」は未検出）
- `No.1` は `No.10` にも一致します（誤検出側）
- `無添加` は「無添加せっけん」など、何が無添加かを併記した文にも一致します（誤検出側）
- 隣接する2語は1本のハイライト帯に統合されます（件数は語の種類で数えるため、件数とハイライトの本数は一致しないことがあります）
- 該当語リストの並び順は、本文の出現順ではなく内蔵リスト順（カテゴリ順）です
- からだの変化（治る・効く・予防できる など）に関わる表現は、この道具では扱っていません
